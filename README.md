# The English Herald 📰

AI destekli İngilizce öğretim platformu — İnsan Tıbbı, Veteriner Tıbbı, Haberler, IELTS ve daha fazlası.

## 🚀 Web'de Yayınlama (GitHub Pages — Ücretsiz)

### Adım 1: GitHub Hesabı
https://github.com adresinden ücretsiz hesap aç.

### Adım 2: Yeni Repo Oluştur
- "New repository" tıkla
- İsim: `english-herald`
- Public seç
- "Create repository" tıkla

### Adım 3: Dosyaları Yükle
Şu 4 dosyayı yükle:
- `index.html`
- `style.css`
- `data.js`
- `app.js`

### Adım 4: GitHub Pages Aktifleştir
- Repo → Settings → Pages
- Source: "Deploy from a branch"
- Branch: `main` → `/root`
- Save

### Adım 5: Sitenin URL'si
```
https://KULLANICI_ADIN.github.io/english-herald
```

## 🔑 API Key Kurulumu

1. https://console.anthropic.com adresine git
2. "API Keys" → "Create Key"
3. Uygulamayı aç → 🔑 butonuna tıkla
4. Key'ini gir → Kaydet

API key yalnızca tarayıcında saklanır, hiçbir sunucuya gitmez.
